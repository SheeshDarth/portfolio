01 Work

NirmiqCodeSensei

A local-first learning OS that turns any project into deep understanding — so you know what you shipped, not just that it runs.

Next.js 16 TypeScript SQLite MCP Local AI

The problem

You use Cursor, Claude Code, or Copilot to build faster, and the code works. But when someone asks why you made a design decision, or what the time complexity is, or how you'd extend it, the answer isn't there — the AI wrote it, you shipped it, you didn't learn it.

The trade-off

CodeSensei's offline analyzer is the default: it reads your source and produces an eight-lens senior-engineer report, an architecture map, and the data structures actually detected in your code — entirely on 127.0.0.1. An API key is optional and only ever enriches a narrative; it never becomes the thing your analysis depends on.
